# Voice script: Little Menu A1–A3, numbers 0–20

Generated by `npm run audio:todo`; do not edit by hand (the build reads the numbers back).

**How to record** (D140c):

1. Quiet room, the mic at a steady distance, an even, friendly pace. Read each line in full, as the game says it; leave a short breath between lines. Several takes are fine.
2. In Audacity select only the **bold** words of the take you keep and press Ctrl+B; type the line's number as the label. One label per number.
3. File → Export Audio: WAV, mono (any sample rate; 48 kHz / 24-bit preferred). File → Export → Export Labels: the same name as the WAV, `.txt`. Both into `voice-masters/full`.
4. Run `npm run audio:build -- --src voice-masters/full`. It reports missing, extra and duplicate numbers before it writes anything.

Script: `docs/VOICE_SCRIPT.md`.
