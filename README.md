# number-chef-monster-cafe
Number Chef: Monster Café - A game for practicing basic arithmetic skills, made for a young child

**Install to the Home Screen before first play.** On iOS, a Home Screen app and the same site opened in a Safari tab keep separate storage, so progress made in the tab does not carry over to the installed app. (iPhone/iPad: Share → Add to Home Screen. Android: Chrome menu → Install app.)

**Back up now and then.** Grown-ups: Home gear → hold the circle → answer the multiplication question → *Data → Back up now*. A backup restores on any device (*Choose a backup file…*), and *Reset this device…* clears playtest progress before real use.

The design lives in `docs/SPEC.md` (source of truth). `docs/DECISIONS.md` indexes the decisions behind it; their full reasoning is in `docs/archive/DECISIONS_LOG.md`.

The Github pages site is live at https://sqlguyjps.github.io/number-chef-monster-cafe/.
