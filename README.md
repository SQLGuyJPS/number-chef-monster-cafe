# number-chef-monster-cafe
Number Chef: Monster Café - A game for practicing basic arithmetic skills, made for a young child

**Install to the Home Screen before first play.** On iOS, a Home Screen app and the same site opened in a Safari tab keep separate storage, so progress made in the tab does not carry over to the installed app. (iPhone/iPad: Share → Add to Home Screen. Android: Chrome menu → Install app.)

The design lives in `docs/SPEC.md` (source of truth), with the reasoning in `docs/DECISIONS.md`.
